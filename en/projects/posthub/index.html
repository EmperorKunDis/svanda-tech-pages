Engineering decisions and tradeoffs

Tenant context in the data model

Organizations and companies anchor content and access.

Editorial reading of source revision c871592844f1, reviewed 2026-10-05. This is not a formal ADR unless explicitly identified below.

Tradeoff: Every API path and background task must carry and validate the right tenant context.

Queue long AI work

Generation time should not hold an HTTP request open.

Editorial reading of source revision c871592844f1, reviewed 2026-10-05. This is not a formal ADR unless explicitly identified below.

Tradeoff: The UI needs durable task state, error handling and recovery; queue lag remains unmeasured here.

Signed billing webhooks

Payment events arrive asynchronously and may be repeated.

Editorial reading of source revision c871592844f1, reviewed 2026-10-05. This is not a formal ADR unless explicitly identified below.

Tradeoff: The transaction and event record implement deduplication, but do not establish an exactly-once guarantee under every failure.

Data, reliability, tests and operations

Source inspected on 14 October 2026 at revision c871592844f1. These observations are source-level, not a new product run or live deployment check.

Data and contracts

Models and migrations separate organizations, companies, content, personas and billing. The signed Stripe webhook records handled events and processes them transactionally; that does not establish an exactly-once guarantee.

Reliability

AI workers use a retry counter, exponential delay, error callback and a reaper for old processing jobs. A dead-letter queue and current runtime recovery are not established here.

Tests and CI

The source includes tenant isolation, webhook and AI dispatch tests. They were not run during the 14 October 2026 review. Historical CI passed on 3 July 2026; the backend gate requires 40% coverage while the frontend check allows a run without tests.

Operations and rollback

The source contains separate services and a deployment workflow. Rolling back a container image does not reverse database migrations. The current production revision and availability were not checked.
