Engineering decisions and tradeoffs

Information architecture first

Extensive UI clarifies relationships between roles, clients and work steps.

Tradeoff: Local demo data does not establish production backend or ERP behavior.

Shared components across roles

Consistent navigation and detail patterns support orientation.

Tradeoff: Role differences need explicit design; hiding UI is not authorization.

Static demo export

GitHub Pages and a custom domain can host the demo.

Tradeoff: Production login, databases and sensitive accounting data need a separate server layer.

These decisions are editorial readings of the cited source, not documented formal ADRs.
