Engineering decisions and tradeoffs

Persist before follow-up

The call outcome needs a stable record before notifications are queued.

Editorial reading of source revision d8f684ecaf6e, reviewed 2026-08-04. This is not a formal ADR unless explicitly identified below.

Tradeoff: A failed follow-up must remain distinguishable from a completed call; retries and locks reduce duplicate processing but need runtime tests.

Separate conversation from staff workflow

The team needs structured purpose and urgency, not only audio.

Editorial reading of source revision d8f684ecaf6e, reviewed 2026-08-04. This is not a formal ADR unless explicitly identified below.

Tradeoff: The agent's interpretation can be wrong and requires a reviewable record.

Bounded logs with optional error export

The accepted 27 July 2026 ADR selected Docker stdout/stderr logs as the baseline with data redaction and optional Sentry.

Editorial reading of source revision d8f684ecaf6e, reviewed 2026-08-04. This is not a formal ADR unless explicitly identified below.

Tradeoff: It rejected Loki's operating cost and using the business AuditLog for telemetry; the review did not prove Sentry is running.

Data, reliability, tests and operations

Source inspected on 14 October 2026 at revision d8f684ecaf6e. These observations are source-level, not a new product run or live deployment check.

Data and contracts

Django/PostgreSQL stores the structured request; phone numbers, transcripts and provider payloads remain private. The source has a health/version output with build SHA, but its current public output was not checked.

Reliability

Post-call processing has bounded retries, a transaction, record lock and an already-processed check. Email, SMS and audio jobs are dispatched after the transaction commits.

Tests and CI

CI defines lint, Django deploy check, backend tests, frontend typecheck/build and E2E. A historical test run passed on 2 August 2026, staging E2E was skipped and the following deployment of that revision failed. This is not a new passing run.

Operations ADR

An accepted 27 July 2026 ADR chooses bounded Docker stdout/stderr logs as the baseline, optional Sentry with data redaction and private source maps. It rejects Loki for operating cost and DB AuditLog for a different purpose. Production Sentry was not verified.
