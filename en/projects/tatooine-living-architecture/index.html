Engineering decisions and tradeoffs

Local terminal control

The canonical workflow keeps operator, task state and review together.

Editorial reading of source revision 1f74fc5885d4, reviewed 2026-08-04. This is not a formal ADR unless explicitly identified below.

Tradeoff: The private local setup is not a public real-time dashboard or a released multi-user service.

Transaction-linked ledger

A recorded event should remain tied to a state change and be inspectable later.

Editorial reading of source revision 1f74fc5885d4, reviewed 2026-08-04. This is not a formal ADR unless explicitly identified below.

Tradeoff: A hash chain improves traceability but does not by itself prove every external action or create immutable off-site evidence.

Bounded execution and human approval

Tasks record their goal, definition of done, verification plan and approval; subprocesses have a timeout and explicit timeout state.

Editorial reading of source revision 1f74fc5885d4, reviewed 2026-08-04. This is not a formal ADR unless explicitly identified below.

Tradeoff: A timeout alone does not prove complete isolation, restart recovery or safe production operation; consequential actions still need the human gate.

Data, reliability, tests and operations

Source inspected on 14 October 2026 at revision 1f74fc5885d4. These observations are source-level, not a new product run or live deployment check.

Data and contracts

A task stores its goal, definition of done, verification plan, approvals, budget and artifact references. The PostgreSQL ledger appends events transactionally under an advisory lock, with a hash chain and redaction.

Reliability

The runner has a subprocess timeout and an explicit timeout state. This boundary alone does not establish restart recovery, isolation of every tool or production readiness.

Tests and AI evaluation

The source includes GoldenCase/GoldenDataset, fingerprints, validation of empty or duplicate data and a benchmark runner. Mock tests and score aggregation exist but were not run here and do not measure real-model quality. Historical remote CI on 23 July 2026 was not green.

Operations and observability

Code records trace/run/step context, event redaction, latency, Prometheus text and alert evaluation. The store is in memory; persistent production telemetry, OpenTelemetry and measured SLOs are not established.

Prototype at review. The internal environment has not been run as part of this review.
