01 / PROBLÉM UŽIVATELE

Co bylo potřeba vyřešit.

PRO KOHO · Účastníci vzdělávacího programu, lektoři a správci jednotlivých běhů.

U delšího kurzu nestačí zpřístupnit materiály. Je potřeba vědět, kdo má přístup, jakou práci odevzdal, co mu lektor vrátil a zda už splnil podmínky absolvování.

02 / VZNIK PROJEKTU

Jak k projektu došlo.

PULS Akademie vznikala jako platforma pro řízené vzdělávací běhy. Zadání spojuje postup účastníka s lektorskou kontrolou a administrací kohort, místo aby se tyto informace rozcházely mezi několika nástroji.

03 / CO PROJEKT OBSAHUJE

Funkce a výsledky pro uživatele.

Kohorty a přístupy

Správce přiřazuje účastníky ke konkrétnímu běhu a jejich roli.

Studijní dny a úkoly

Obsah rozlišuje úkoly, mise, návyky a závěrečné projekty.

Odevzdání a review

Každá práce má stav a revizi; lektor ji schválí nebo vrátí se zpětnou vazbou.

Pokrok a certifikace

Aplikace propojuje dokončenou práci, odměny, přehled a vydání certifikátu.

04 / JAK ŘEŠENÍ POMÁHÁ

Co se pro uživatele mění.

Student odevzdává důkazy práce a lektor rozhoduje nad konkrétní revizí. Výsledek se propisuje do pokroku a navazujících odměn; certifikát vychází z kontrolovaných podmínek absolvování.

05 / BĚŽNÝ PRŮBĚH

Jak se s projektem pracuje.

  1. 01

    Získá přístup

    Správce zařadí účastníka do běhu kurzu.

  2. 02

    Otevře dnešní zadání

    Účastník projde dostupný obsah a připraví požadovaný výsledek.

  3. 03

    Odevzdá důkaz práce

    Připojí text, odkaz nebo soubor podle typu úkolu.

  4. 04

    Lektor práci posoudí

    Schválí konkrétní revizi nebo ji vrátí k dopracování s komentářem.

  5. 05

    Pokračuje nebo práci opraví

    Student naváže podle rozhodnutí. Po splnění podmínek může získat certifikát.

MOJE PRÁCE

Od návrhu k realizaci.

Angular klient komunikuje s Django REST API. Domény rozdělují účty, kohorty, obsah, odevzdání, hodnocení a certifikáty. PostgreSQL uchovává stav a audit, Celery řeší následné úlohy a MinIO soubory. Schválení revize probíhá transakčně a navazující úlohy se spouštějí po commitu.

Technologický stack
  • Angular
  • Django
  • Django REST Framework
  • PostgreSQL
  • Celery
  • Redis
  • MinIO
