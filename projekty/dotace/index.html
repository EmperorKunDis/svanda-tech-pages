Dotační výzvy jsou rozptýlené v různých veřejných katalozích a mají odlišně zapsané termíny. Ruční procházení všech zdrojů je pomalé.

02 / VZNIK PROJEKTU

Jak k projektu došlo.

Produkt vznikl jako agregátor veřejných dotačních zdrojů. Auditovaný snapshot zahrnoval 17 zdrojů; žádné jednotlivé zadání klienta není doložené.

03 / CO PROJEKT OBSAHUJE

Funkce a výsledky pro uživatele.

Sjednocené výzvy

Pipeline normalizuje a deduplikuje položky z katalogů a sitemap.

Rychlé hledání

Statický web nabízí fulltext, filtry a řazení bez účtu.

Původní dokument

Záznam vede k oficiální výzvě a přílohám pro potvrzení podmínek.

04 / JAK ŘEŠENÍ POMÁHÁ

Co se pro uživatele mění.

Týdenně obnovovaný read-only přehled sjednocuje položky a umožňuje hledat a filtrovat. Každá výzva odkazuje k původnímu oficiálnímu zdroji.

  1. 01

  2. 02

    Porovnat výzvy

    Ověřit u zdroje

    Před rozhodnutím otevře oficiální výzvu; agregátor není rozhodující autorita.

DŮKAZY / E1–E8

Co je doložené a co čeká na ověření

Stav „popsáno“ vychází z historického auditu zdroje. Neznamená aktuální běh testů, nasazenou revizi ani měřený výsledek. Procentní skóre z těchto oblastí nepočítáme.

E1 · Scaffolding
Popsáno v podkladech — Python pipeline vytváří statický dataset pro HTML/JS frontend.
E2 · Contracts
Nezjištěno — Pro tuto oblast zatím není zveřejněn dostatečný podklad.
E3 · Data
Popsáno v podkladech — Data normalizuje, deduplikuje a validuje se stabilními identifikátory.
E4 · Workers
Popsáno v podkladech — Týdenní batch aktualizace běží v GitHub Actions; DLQ není doložena.
E5 · Tests
Popsáno v podkladech — Historický audit zachytil selhání časově závislého testu.
E6 · AI evaluation
Nevztahuje se — Deterministický agregátor veřejných záznamů bez AI evaluace.
E7 · CI/CD
Popsáno v podkladech — GitHub Actions aktualizují data a publikují Pages.
E8 · Observability
Nezjištěno — Pro tuto oblast zatím není zveřejněn dostatečný podklad.
