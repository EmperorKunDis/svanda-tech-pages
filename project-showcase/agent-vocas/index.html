Agent VOCAS

Katalogový popis: Agent VOCAS je hlasový konverzační agent postavený jako součást projektu Tatooine. Zpracovává mluvený vstup, vede dialog a reaguje hlasem v reálném čase pomocí agentní architektury nad voice AI modely.. Aktuální funkčnost není v portfoliu doložena.
